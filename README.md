# Manga Tag Lens · 漫画标签透镜

油猴脚本。在漫画列表页输入标签，简体繁体和英文大小写算同一个，多个标签可以「同时要」或「有一个就行」。对上的漫画整格亮起来，并排到这一片列表的最前面。

搜索词：油猴、Tampermonkey、漫画标签、简繁、高亮、禁漫天堂、jmcomic、18comic、MangaDex。

安装地址（用浏览器打开，交给油猴。以后版本号变大时它会自己更新）：

https://cdn.jsdelivr.net/gh/toocutetop/manga-tag-lens@main/src/manga-tag-lens.user.js

`raw.githubusercontent.com` 在国内经常打不开或显示 404。上面这个 jsDelivr 地址指向同一份脚本。

## 一句话说清它解决什么问题

| 现状 | 装上之后 |
|---|---|
| 想按标签找，只能点一次跳一页 | 在当前页打标签，对上的漫画整块亮出来 |
| 简体、繁体、大小写各算一个 | `无修正` 和 `無修正`、`NTR` 和 `ntr` 算同一个 |
| 一次只能看一个标签 | 可以加多个，选「同时要」或「有一个就行」 |

**一句话**：不跳页，在当前列表里把要找的漫画照亮。

## 怎么用（3 步）

**第 1 步 · 装脚本**

1. 浏览器先装 **Tampermonkey**（篡改猴）。
2. 用浏览器打开上面的安装地址，油猴会弹出安装。
3. 安装时会再下载一次 OpenCC（简繁转换库），这一下要能上网。下完就留在本地。

已经手动贴过旧脚本的，装完后在油猴里删掉旧的那份，避免两份一起跑。

油猴默认隔一段时间检查更新。想马上换成新版：打开该脚本的详情，点「检查更新」。版本号没变时，它不会重新下载。

**第 2 步 · 打开漫画站的列表页**

打开任意漫画站的「漫画列表 / 分类 / 搜索结果」页面。右上角会自动出现一块浮动面板。

> 没出现？说明这个网站还没被适配，看下面「怎么加新网站」。

**第 3 步 · 输入标签**

| 操作 | 效果 |
|---|---|
| 输入后回车，或点下面的词 | 记下这个标签。这一页还没有的词也能加，换页后继续对。逗号可以一次加多个 |
| **同时要 / 有一个就行** | 同时要＝每本都得带上全部已选标签；有一个就行＝带上任意一个就亮 |
| 正在输入时 | 对得上的标签排到列表最前，按回车加入最吻合的那一个 |
| **点顶部整条** | 展开或收起面板。按住同一条可以拖动。收起后仍显示已记的标签数 |
| **跳到下一本** | 滚到下一部亮着的漫画。当前这本是冷色玻璃，其余对上的是暖色玻璃 |
| **清空已选** | 单独一行的按钮。去掉已选标签和高亮，页面回到原样。没选标签时它是淡的，按了没反应 |

对上的整块漫画是一圈暖色液体玻璃，卡片里对上的词会排到那一行标签的最前面，顺序和你选择的顺序一样，并且整格排到这一片列表的最前面。专辑页的「相关漫画」也一样，对上的排到这一排最前。没对上的会变淡。点「跳到下一本」时，正在看的那一本换成冷色液体玻璃，左上角是玻璃角标「当前 2/10」。点「清空已选」后顺序和样式都回到原来。

面板是液态玻璃：边缘会折一下后面的画面，顶部有一条亮边，中间透出页面。已经记下、但这一页还没有的标签会留在上面，标成「未出现」。

## 它凭什么能在不同网站上都工作

漫画站的 HTML 结构天差地别。所以脚本把「网站差异」全部塞进一个东西：**适配器（Adapter）**。

- 每个适配器只管两件事：**标签在哪**、**漫画条目的 DOM 是什么**。
- 引擎（筛选逻辑、面板 UI、AND/OR 算法）对所有网站**完全一致**。
- 因此：加一个新网站 = 在 `ADAPTERS` 数组里加一个对象，**不用碰引擎一行代码**。

### 当前内置适配器

| 适配器 | 覆盖范围 | 状态 |
|---|---|---|
| `jmcomic` | 禁漫天堂（`jmcomic.me` 及同模板的 `jmcomic*` / `18comic`）。分类、搜索、首页底部「最新漫画」能取到 `a.tag`。首页顶部轮播的 HTML 里没有标签 | ✅ 已实现 |
| `mangadex` | MangaDex 列表页 | ✅ 已实现（示例） |
| `generic` | 通用兜底，靠 `href` 含 `tag`、`class` 含 `tag`、`data-tags` 属性等线索自动识别 | ✅ 已实现 |
| 其他站点 | — | ⏳ 待你补充 |

**关于 `generic` 的正确期待**：它能覆盖设计比较规范的站点，命中率不保证 100%。遇到不工作的网站，请按 `docs/adapter-guide.md` 写专属适配器——**这才是这个项目的正确用法**。

## 常见问题

**Q：面板没出现？**
先按 `F12` 打开控制台，看是否有 `[MTL]` 开头的日志。
- 有日志说「未识别到带标签的漫画条目」→ 该站需要写适配器。
- 完全没有日志 → 页面是纯异步加载且超过了重试次数。点油猴图标 → 「重新扫描本页」。

**Q：高亮关不掉？**
点「清空」，或从油猴菜单点「清除高亮」。脚本不改网站数据，刷新就回到原样。

**Q：标签显示不全？**
面板最多列 400 个。输入几个字，对得上的会排到前面。

**Q：简体繁体没折到一起？**
看控制台有没有 `[MTL] … 简繁 OpenCC`。如果是「仅大小写」，说明保存脚本时 OpenCC 没下载成功。联网后在油猴里再保存一次脚本。

**Q：数据存在哪？**
已选标签和「同时要 / 有一个就行」存在 Tampermonkey 本地，不上传。
